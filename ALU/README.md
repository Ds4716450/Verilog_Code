# 8-bit ALU using Verilog HDL

## 1. Project Overview

An Arithmetic Logic Unit (ALU) is one of the fundamental building blocks of a processor. It performs arithmetic and logical operations on binary data based on a control signal.

In this project, an **8-bit ALU** is designed and implemented using **Verilog HDL**.

The ALU accepts two 8-bit operands and performs different arithmetic and logical operations according to the selected operation.

The project covers:

- RTL design using Verilog HDL
- Arithmetic operations
- Logical operations
- Combinational circuit design
- Testbench development
- Functional simulation
- Waveform analysis
- RTL synthesis
- Netlist generation

---

## 2. Functional Description

The 8-bit ALU takes two 8-bit input operands, `A` and `B`, and performs the selected arithmetic or logical operation based on the control signal `ALU_Sel`.

### Inputs

- `A[7:0]` – First 8-bit operand
- `B[7:0]` – Second 8-bit operand
- `ALU_Sel` – Operation-select control signal

### Output

- `ALU_Out[7:0]` – 8-bit result generated by the selected ALU operation

The basic data flow is:

```text
        A[7:0]
           |
           |
           v
      +-----------+
      |           |
B[7:0]|    ALU    |-----> ALU_Out[7:0]
      |           |
      +-----------+
           ^
           |
       ALU_Sel
