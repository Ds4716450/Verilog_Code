# Verilog RTL Design Portfolio

This repository contains my RTL design and verification projects
implemented using Verilog/SystemVerilog.

## Projects

| Project | Description |
|---------|-------------|
| Program Counter | Sequential processor component |
| MUX | Multiplexer RTL designs |
| Decoder | Combinational decoder designs |
| Encoder | Encoder RTL designs |
| ALU | Arithmetic Logic Unit |
| FIFO | Synchronous/Asynchronous FIFO |
| UART | UART transmitter and receiver |
